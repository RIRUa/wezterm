# wezterm

個人用の WezTerm 設定です。

## 構成

| ファイル | 内容 |
| --- | --- |
| `wezterm.lua` | WezTerm の設定本体 |
| `tmux-bg.sh` | tmux の現在の window 番号を WezTerm のユーザー変数 (`tmux_window`) として通知するスクリプト |
| `backgrounds/` | 背景画像 |
| `.mise.toml` | [mise](https://mise.jdx.dev/) で管理するツール (`gh`) |
